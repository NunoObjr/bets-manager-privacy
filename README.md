# Bets Manager — Política de Privacidade

Página estática com a **Política de Privacidade** do aplicativo [Bets Manager](https://github.com/NunoObjr/finance_control), exigida pelas lojas de aplicativos (como a Google Play) para publicação.

## Conteúdo

O documento ([`index.html`](index.html)) informa, em português, que o aplicativo:

- não coleta, armazena nem compartilha dados pessoais;
- guarda tudo apenas localmente no dispositivo do usuário;
- não usa APIs externas nem transmite dados pela internet;
- permite excluir os dados a qualquer momento (removendo o app ou pelas opções internas);
- disponibiliza um e-mail de contato e indica a data da última atualização.

## Publicação

O site é um único arquivo HTML/CSS sem dependências e pode ser servido por **GitHub Pages**:

1. Em *Settings → Pages*, selecione a branch `main` e a pasta `/ (root)`.
2. A URL publicada (`https://<usuario>.github.io/bets-manager-privacy/`) é a informada no formulário de política de privacidade da loja.

## Manutenção

Ao alterar o comportamento do app (por exemplo, adicionar análise, anúncios, backup em nuvem ou qualquer envio de dados), **atualize este documento** e a data de "Última atualização" antes de publicar uma nova versão do app.
